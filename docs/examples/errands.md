# Errands consumer example

An Errands host can define `kind: delivery_evidence`, `valueType: image`, runner
provider policy, workflow-stage lifecycle, progressive client reveal, submission
location, and client verification. These identifiers belong to Errands, not the
core protocol. The full canonical example is
`tests/fixtures/specification/delivery-evidence-v3.json`; its v3 snapshot proves
that later definition edits do not rewrite running work.
